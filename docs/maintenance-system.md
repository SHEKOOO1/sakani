# توثيق نظام الصيانة والمرافق (Maintenance & Facilities System)

## نظرة عامة
تم تصميم نظام الصيانة لضمان سرعة الاستجابة للأعطال الفنية داخل المجمع السكني، مما يحافظ على جودة الحياة وسلامة المنشآت.

## رحلة بلاغ الصيانة

### 1. فتح البلاغ (Reporting)
- يمكن للطالب أو المشرف فتح بلاغ صيانة جديد.
- يتضمن البلاغ: وصف العطل، المكان (رقم الغرفة)، ومستوى الأولوية.

### 2. مستويات الأولوية (Priority Levels)
- 🔴 **عاجل جداً (Urgent)**: للأعطال التي تهدد السلامة أو تعطل الحياة (مثل تسريب مياه رئيسي أو عطل كهربائي كلي).
- 🟠 **أولوية عالية (High)**: للأعطال الهامة (مثل تعطل تكييف أو سخان).
- 🔵 **عادي (Medium)**: للإصلاحات الدورية والأعطال البسيطة.

### 3. التعيين والمتابعة (Assignment)
- يقوم الأدمن أو المشرف بتعيين البلاغ لموظف صيانة محدد.
- تتغير حالة البلاغ من "قيد الانتظار" إلى "جاري العمل" بمجرد بدء الإصلاح.

### 4. الإغلاق والأرشفة (Completion)
- عند الانتهاء، يتم تحويل الحالة إلى "تم الإصلاح".
- يتم حفظ سجل الإصلاحات لكل غرفة لتقييم كفاءة المرافق وتحديد احتياجات الإحلال والتجديد.

## واجهة المستخدم (Dashboard)
- **بطاقات المهام**: تعرض كل بلاغ في بطاقة منفصلة توضح التفاصيل، الأولوية، والحالة بشكل بصري واضح.
- **تنبيهات الأولوية**: استخدام الألوان (أحمر، برتقالي، أزرق) لجذب الانتباه للأعطال الأكثر إلحاحاً.
- **إدارة الطاقم**: قائمة منسدلة لاختيار الموظف المسؤول بناءً على تخصصه.

## نصائح الاستخدام
1. يرجى وصف العطل بدقة (مثال: "صنبور مياه مكسور في حمام الغرفة 302") لتسريع جلب قطع الغيار المناسبة.
2. استخدام الأولوية "عاجل جداً" فقط في الحالات الطارئة لضمان عدم تأخير الأعطال الحرجة الأخرى.

---
*هذا النظام يربط الطالب بالإدارة الفنية لضمان سكن مريح وآمن للجميع.*
