# توثيق نظام إدارة الطلاب والأرشفة (Students & Archiving System)

## نظرة عامة
يوفر هذا النظام دورة حياة كاملة للطالب داخل السكن، بدءاً من التسجيل المبدئي وصولاً إلى التخرج والأرشفة النهائية، مع تتبع دقيق لأولياء الأمور.

## دورة حياة الطالب

### 1. التسجيل والقبول
- يتم تسجيل الطالب ببياناته الشخصية، الجامعية، والديانة.
- يتم ربط الطالب بغرفة محددة آلياً وتحديث سعة الغرفة.
- يتم إنشاء حساب دخول (Login) للطالب فور تسجيله.

### 2. ربط أولياء الأمور (Guardian Link)
- يسمح النظام بإضافة أكثر من ولي أمر (أب، أم، قريب).
- يمكن ربط حسابات أولياء الأمور لإرسال إشعارات السلوك والغياب إليهم تلقائياً.
- تظهر بيانات التواصل السريع (واتساب، اتصال) في ملف الطالب للمشرفين.

### 3. نظام الأرشفة الذكي (Smart Archiving)
عند مغادرة الطالب للسكن (تخرج، انسحاب، أو فصل)، يتم تنفيذ الآتي:
- **إخلاء المكان**: يتم تحرير سرير الطالب في الغرفة المسكن بها فوراً.
- **تجميد الحساب**: يتم إغلاق صلاحيات دخول الطالب للتطبيق.
- **حفظ السجل التاريخي**: يتم نقل بيانات الطالب إلى "الأرشيف" مع حفظ:
    - سبب المغادرة (تخرج، انسحاب، إلخ).
    - تاريخ المغادرة الدقيق.
    - لقطة (Snapshot) من كافة بيانات الطالب وقت المغادرة للرجوع إليها مستقبلاً.

## واجهة الأرشيف
تتميز واجهة الأرشيف بترميز لوني يسهل التمييز بين حالات المغادرة:
- 🟢 **الأخضر**: للطلاب الخريجين.
- 🔴 **الأحمر**: للفصل الإداري.
- 🟠 **البرتقالي**: للانسحاب بناءً على الرغبة.

## التقنيات المستخدمة
- استخدام `ConfirmationModal` لضمان عدم الأرشفة عن طريق الخطأ.
- الربط مع واجهة البرمجة (API) عبر المسارات:
    - `/api/students/archive`: لجلب البيانات المؤرشفة.
    - `/api/students/:id/leave`: لتنفيذ عملية المغادرة.
