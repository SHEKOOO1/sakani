# تحديثات نظام السكن - مايو 2026

تمت إضافة مجموعة من المميزات الجديدة لتسهيل إدارة السكن الجامعي وتوفير معلومات تفصيلية عن الشقق والغرف، بالإضافة إلى تحسين النظام المالي.

## 1. تفاصيل الشقق (Apartments)
تمت إضافة حقول تفصيلية لكل شقة تشمل:
- **المرافق العامة**: (تكييف، مروحة، شاشة تلفزيون، واي فاي).
- **المطبخ**: إمكانية تحديد ما إذا كان للسكن مطبخ خاص وتفصيل تجهيزاته (ثلاجة، بوتاجاز، سخان، إلخ).
- **الحمام**: إمكانية تحديد تجهيزات الحمام (سخان غاز/كهرباء، غسالة ملابس).

## 2. تفاصيل الغرف والأسعار (Rooms & Pricing)
تم تطوير نظام تسعير مرن لكل غرفة:
- **السعر اليومي**: للإقامات القصيرة أو الزيارات.
- **السعر الشهري**: للمغتربين بنظام الشهر.
- **سعر الترم الدراسي**: عرض خاص للطلاب المقيمين طوال الفصل الدراسي.
- **محتويات الغرفة**: تحديد الأثاث المتاح (مكتب، دولاب، تكييف، إلخ).

## 3. الأترام الدراسية (Academic Semesters)
يمكن لمشرف السكن الآن من صفحة الإعدادات تحديد:
- تاريخ بداية ونهاية الترم الأول.
- تاريخ بداية ونهاية الترم الثاني.
هذه التواريخ تساعد في ضبط الفواتير والتقارير المالية للطلاب المقيمين بنظام "الترم".

## 4. تسكين الطلاب (Student Placement)
عند تسجيل طالب جديد أو تعديل بياناته:
- يتم اختيار الغرفة المتاحة.
- يتم اختيار **نظام المحاسبة** (يومي/شهري/ترم).
- يتم جلب السعر تلقائياً من إعدادات الغرفة مع إمكانية تعديله للطالب يدوياً (السعر المتفق عليه).

---
*ملاحظة: جميع البيانات تُحفظ بشكل مشفر وآمن في قاعدة البيانات لضمان خصوصية الطلاب والإدارة.*
