# نظام إدارة الأدوار والصلاحيات (RBAC) 🛡️

تم تصميم هذا النظام لضمان أعلى مستويات الأمان والتنظيم داخل سكن الطلاب، حيث يتم الفصل التام بين الأدوار المختلفة وتوزيع الصلاحيات بناءً على المسؤوليات.

## الأدوار المتاحة وصلاحياتها:

### ١. مدير التطبيق (Admin) 👑
- السلطة الكاملة على النظام بأكمله.
- إدارة السكنات (Tenants) وإضافة سكنات جديدة.
- التحكم في الإعدادات العامة للمنظومة.
- الوصول لجميع التقارير والإحصائيات.

### ٢. الأب الأسقف (Bishop) ⛪
- دور إشرافي رفيع المستوى.
- عرض التقارير الإجمالية للأبرشية.
- متابعة الأداء العام للسكنات التابعة له.

### ٣. الأب الكاهن (Priest) 📿
- دور إرشادي وروحي.
- متابعة الطلاب والأنشطة والمسابقات.
- عرض التقارير الخاصة بالطلاب لمتابعة حالتهم.
- لا يملك صلاحيات تعديل البيانات الإدارية أو المالية.

### ٤. مشرف السكن (Supervisor) 👨‍💼
- **السلطة التشغيلية المطلقة** داخل السكن المسؤول عنه.
- التحكم في مواعيد الحضور والانصراف (Curfew).
- تحديد نقاط الـ GPS للدخول والخروج والقطر المسموح به.
- إدارة الموظفين وتعيين الأدوار لهم داخل السكن.
- إدارة المغسلة، المسابقات، الدرجات، الحضور، والمالية.
- إرسال تنبيهات الغياب الجماعية لأولياء الأمور.

### ٥. الموظف (Employee) 👷
- مهام تنفيذية محددة.
- تسجيل الحضور والغياب اليدوي.
- التعامل مع طلبات الصيانة.
- إدارة طوابير المغسلة.

### ٦. الطالب (Student) 🎓
- دور تفاعلي فقط (لا يملك أي تحكم في المواعيد).
- **الأنشطة والمسابقات والفعاليات**: يظهر له تبويب موحد باسم "الأنشطة والمسابقات والفعاليات" يجمع كافة العناصر للعرض والتفاعل فقط (مثل الاشتراك أو التعليق).
- **منع الإنشاء**: لا يحق للطالب نهائياً إنشاء (نشاط، مسابقة، فعالية، أو فريق) من تلقاء نفسه.
- **صلاحيات الإدارة الاستثنائية**: لا تظهر له أي أزرار تحكم (تعديل، حذف، رصد درجات) إلا إذا منحه المشرف صلاحية "مسؤول" على عنصر محدد بذاته عبر نظام `item_managers`.
- تسجيل الحضور والإنصراف عبر GPS، وعرض رمز الـ QR.
- تقديم طلبات الصيانة والغسيل، وعرض رصيد النقاط والمكافآت.
- تسجيل حالة السفر والعودة.

### ٧. ولي الأمر (Parent) 👨‍👩‍👦
- لوحة تحكم شاملة لمتابعة الابن.
- عرض التقارير المالية (المدفوعات والمستحقات بالتفصيل).
- متابعة سجل الحضور والإنصراف اليومي.
- استلام إشعارات فورية عند دخول/خروج الابن أو تأخره.
- عرض التحذيرات والدرجات والمكافآت التي حصل عليها الابن.

## ميزات الأمان المضافة:
- **تحقق Geofencing**: لا يمكن للطالب تسجيل حضور إلا إذا كان داخل النطاق الجغرافي المحدد من قبل المشرف.
- **تنبيهات تلقائية**: يتم إخطار ولي الأمر والمشرف فوراً في حال تأخر الطالب عن موعد غلق السكن.
- **إشعارات غياب ذكية**: يمكن للمشرف بضغطة زر تنبيه جميع أولياء أمور الطلاب الذين لم يحضروا للسكن بعد فوات الموعد.
- **فصل البيانات**: كل مشرف يرى ويدير فقط السكن المخصص له، ولا يسمح بتداخل البيانات بين السكنات المختلفة.
