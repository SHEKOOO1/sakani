# مكونات الواجهة الأمامية (Frontend Components)

يحتوي هذا المجلد على كل صفحات الموق وأجزاء الواجهة.

## الهيكل التنظيمي للمكونات:

### 1. صفحات الإدارة (Application Management)
- **AdminSystemPage.tsx**: مخصصة لمدير المنظومة لإنشاء السكنات وإدارة الإعدادات العالمية.
- **EmployeesPage.tsx**: إدارة الموظفين وتوزيع أدوارهم.

### 2. صفحات الإشراف (Building Supervision)
- **ApartmentsPage.tsx** & **RoomsPage.tsx**: مخصصة للمشرف لإدارة التسكين الفعلي.
  - **تحديث**: تم إضافة شريط تقدم (Occupancy Bar) تفاعلي يغير ألوانه بناءً على نسبة الامتلاء (أزرق -> برتقالي -> أحمر).
  - **تحديث**: تم حصر العمليات الإدارية (إضافة، حذف، تعديل) لمن يملك صلاحية `MANAGE_HOUSING` حصراً.
- **AttendancePage.tsx**: تسجيل حضور الطلاب في السكن.
- **LaundryPage.tsx**: إدارة طابور المغسلة الآلي.

### 3. صفحات المتابعة (Monitoring & Reports)
- **BishopReportsPage.tsx**: تقارير مجمعة للأسقف.
- **FinancePage.tsx**: متابعة الحركة المالية لكل سكن.
- **DecisionsLog.tsx**: أرشفة القرارات الإدارية.

### 4. المكونات المشتركة
- **Layout.tsx**: يحدد شكل الموقع (Sidebars, Headers) ويقوم بإخفاء/إظهار القوائم بناءً على **صلاحيات المستخدم**.
- **NotificationBell.tsx**: نظام التنبيهات اللحظية.

## مبدأ التصميم:
- تم استخدام **Tailwind CSS** للتصميم العصري.
- تم استخدام **Framer Motion** لإضافة حيوية وحركات انسيابية للواجهة.
- الواجهة بالكامل تدعم اللغة العربية واتجاه اليمين إلى اليسار (RTL).
