# الواجهة الأمامية والمكونات (Frontend & Components)

تركز واجهة DormMaster على تجربة المستخدم (UX) من خلال تصميم نظيف، تفاعلي، ويدعم اللغة العربية بشكل كامل (RTL).

## الفلسفة التصميمية
*   **التفاعلية:** استخدام مكتبة `motion` لإعطاء انطباع حيوي للمسارات والتحولات.
*   **الوضوح:** توزيع العناصر في "شبكات" (Grids) وبطاقات (Cards) لتسهيل قراءة المعلومات الكثيفة.
*   **التناسق:** الاعتماد على Tailwind CSS لضمان تناسق الألوان والمساحات في كل الصفحات.

## المكونات الأساسية

### المكونات الهيكلية
*   `Layout.tsx`: الإطار العام للتطبيق الذي يحتوي على القائمة الجانبية (Sidebar) وشريط البحث العلوي.
*   `ConfirmationModal.tsx`: مكون موحد لحماية البيانات من الحذف العرضي، يظهر عند القيام بأي عملية حذف.

### الصفحات الوظيفية
*   `Dashboard.tsx`: مركز التحكم الرئيسي، يعرض إحصائيات سريعة للطلاب، الغرف، والمالية (تم تحديث التصميم ليصبح أكثر حداثة وتفاعلية باستخدام خط Cairo).
*   `StudentsPage.tsx`: واجهة إدارة الطلاب والبحث المتقدم.
*   `FinancePage.tsx`: لوحة عرض العمليات المالية مع ملخص للإيرادات والمصروفات.
*   `MaintenancePage.tsx`: نظام بطاقات الصيانة الملونة لتوضيح الأولوية وحالة البلاغ.
*   `AdminSystemPage.tsx`: واجهة التحكم المركزية التي تتيح للمدير العام إضافة الأساقفة والسكنات والتعيينات الإدارية.
*   `SettingsPage.tsx`: التحكم في صلاحيات الأدوار وإدارة المستخدمين الجدد.

## إدارة الحالة (State Management)
*   **AuthContext:** يدير جلسة المستخدم وحفظ بيانات الدخول في `localStorage`.
*   **useApi Hook:** يوفر طريقة موحدة وآمنة لإرسال الطلبات للخلفية مع التعامل التلقائي مع رموز التحقق.
