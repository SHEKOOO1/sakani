# التحديثات الجديدة في نظام إدارة السكن

تم إضافة مجموعة من الميزات الذكية لتحسين مراقبة حضور الطلاب وضمان سلامتهم وتسهيل التواصل مع أولياء الأمور والمشرفين.

## 1. نظام الحضور الجغرافي المتقدم (Geofencing)
- **نقاط دخول وخروج مخصصة**: يمكن الآن للمشرفين تحديد نقطة جغرافية محددة للدخول (مثل الباب الأمامي) ونقطة أخرى للخروج.
- **قطر مخصص**: يمكن تحديد القطر المسموح به لكل نقطة بالمتر لضمان الدقة (مثلاً 50 متر حول الباب).
- **إعدادات عامة**: إذا لم يتم تحديد نقاط دخول/خروج مخصصة، سيستخدم النظام الموقع العام للمجمع السكني.

## 2. نظام ميعاد غلق السكن (Curfew)
- **وقت الغلق**: يمكن تحديد وقت رسمي لغلق باب السكن (مثلاً 10:00 مساءً).
- **تتبع التأخير**: إذا قام الطالب بتسجيل "دخول" بعد هذا الوقت، يتم تسجيل العملية كـ "تأخير" (Late) تلقائياً.
- **سجل التأخيرات**: يتم تسجيل كل تأخير في قائمة مخصصة تظهر في ملف الطالب للمشرفين، ولا يمكن حذفها لضمان المتابعة الإدارية.

## 3. نظام سفر الطالب
- **تسجيل السفر**: يستطيع الطالب الآن إخطار النظام بأنه "مسافر" مع تحديد الوجهة والسبب.
- **استثناء من التأخير**: بمجرد تسجيل حالة "السفر"، يتم إعفاء الطالب تلقائياً من تسجيلات التأخير، حيث يتم تعطيل زر تسجيل الحضور حتى يعلن الطالب عودته.
- **العودة**: عند عودة الطالب، يضغط على "عدت من السفر" لإعادة حالة الحضور الطبيعية.

## 4. نظام الإشعارات الفورية
يعمل النظام على إرسال إشعارات تلقائية في الحالات التالية:
- **عند الدخول أو الخروج**: إخطار المشرفين وأولياء الأمور بموعد الحركة.
- **عند التأخير**: إشعار "تحذير" للأهل والمشرفين بأن الطالب قد دخل السكن بعد الموعد المحدد.
- **عند السفر والعودة**: إخطار الطرفين فور بدء السفر وفور العودة بسلامة لضمان الطمأنينة.
