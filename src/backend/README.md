# البنية التحتية للخلفية (Backend Architecture)

هذا المجلد يحتوي على كل ما يتعلق بمنطق العمل، قواعد البيانات، والواجهة البرمجية (API).

## الأقسام الرئيسية

### 1. واجهة البرمجة (API Routes)
تم تقسيم المسارات بناءً على الوظائف:
*   `auth.routes.ts`: مسؤول عن تسجيل الدخول، إنشاء الحسابات، وتوزيع رموز التحقق (JWT).
*   `tenant.routes.ts`: إدارة المؤسسات السكنية المشتركة في النظام.
*   `student.routes.ts`: العمليات الخاصة ببيانات الطلاب وتسكينهم.
*   `finance.routes.ts`: معالجة العمليات المالية والتقارير.
*   `maintenance.routes.ts`: إدارة دورة حياة بلاغات الصيانة.

### 2. البنية التحتية (Infrastructure)
*   **قاعدة البيانات (`db.ts`):** نستخدم SQLite لسهولة التوزيع والأداء العالي. يتم تفعيل القيود (Foreign Keys) لضمان سلامة البيانات.
*   **التشفير:** يتم تشفير كلمات المرور باستخدام `bcryptjs` قبل تخزينها.

### 3. الصلاحيات (Middleware)
*   `authenticate`: يتأكد من أن المستخدم يمتلك رمز دخول صالح.
*   `authorize`: يتحقق من دور المستخدم (مدير، مشرف، طالب) قبل السماح بالوصول لمصادر معينة.
*   `tenantGuard`: تضمن عزل البيانات بشكل كامل بحيث لا يمكن لمستخدم رؤية بيانات مجمع سكني آخر.

## منطق العمل (Domain Logic)
يحتوي مجلد `domain` على التعريفات (Interfaces) والأنواع (Types) التي تضمن تناسق البيانات بين الواجهة الأمامية والخلفية.
