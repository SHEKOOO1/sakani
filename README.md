# نظام إدارة السكن الجامعي الذكي

تم تطوير هذا التطبيق لتسهيل وإدارة كافة جوانب السكن الجامعي، مع التركيز على الكفاءة، التنظيم، والتواصل الفعال بين الإدارة، الطلاب، وأولياء الأمور.

## المميزات الرئيسية للمشروع

### 1. نظام إدارة الفعاليات والأنشطة (Event Management System)
هذا النظام هو القلب النابض للتطبيق حالياً، ويشمل:
- **تحكم كامل بالفعاليات**: إمكانية إنشاء فعاليات كبرى (مؤتمرات، يوم رياضي، إلخ) مع تحديد الموقع الجغرافي (Geofencing) والسعر والمسؤولين.
- **إدارة الأقسام الفرعية (Sessions)**: داخل كل فعالية يمكن إضافة "سيشنات" أو محاضرات أو صلوات، مما يسمح بتنظيم دقيق للوقت.
- **نظام الحضور الذكي بالـ QR**: يمكن للمشرفين أخذ الحضور عن طريق فتح الكاميرا وقراءة الكود الخاص بكل طالب، مع دعم كامل لمسح الحضور الخاص بجلسة معينة (Session) مباشرة من قائمة الجلسات.
- **إدارة الغياب والاعتذارات**: إمكانية تسجيل أسباب الغياب (مرض، سفر، إلخ) مع خيار إبلاغ ولي الأمر أو الأب الكاهن تلقائياً.
- **تقارير إحصائية شاملة**: عرض نسب الحضور والغياب بصورة رسومية وجداول تفصيلية لكل قسم فرعي.

### 2. إدارة السكن المتطورة (Advanced Housing Management)
- **تفاصيل الشقق والغرف**: إمكانية إضافة مرافق تفصيلية (تكييف، واي فاي، مطبخ مجهز، إلخ).
- **نظام تسعير مرن**: دعم الأسعار (اليومية، الشهرية، والترم الدراسي) لكل غرفة على حدة.
- **إدارة الأترام الدراسية**: تحديد مواعيد الأترام لضبط الفواتير والتقارير المالية.
- **تسكين الطلاب المالي**: ربط الطالب بغرفة محددة وبنظام محاسبة متفق عليه.

### 3. إدارة السلوك والانضباط (Behavior & Discipline)
- **سجل النقاط**: نظام مكافآت ونقاط لتشجيع الطلاب على الانضباط والمشاركة.
- **الإنذارات**: إمكانية إصدار إنذارات بمستويات مختلفة (منخفض، متوسط، عالٍ، حرج) مع توثيق الأسباب وإرسال إشعارات فورية لأولياء الأمور.

### 3. إدارة الطلاب والأرشفة (Student Management & Archiving)
- **ملفات تعريف شاملة**: لكل طالب ملف يحتوي على بياناته الأكاديمية والشخصية وبيانات ولي أمره.
- **نظام الأرشفة الذكي**: عند تخرج الطالب أو مغادرته للسكن، يتم أرشفة بياناته مع حفظ كافة سجلاته (الاسم، الرقم الجامعي، بيانات التواصل) لسهولة استرجاعها مستقبلاً.
- **ربط أولياء الأمور**: إمكانية إضافة حسابات خاصة لأولياء الأمور لمتابعة حضور وسلوك أبنائهم.

### 4. الإدارة المتعددة والصلاحيات (Multi-Tenancy & Roles)
- **تعدد التعيينات**: يمكن للأنبا الأسقف تعيين أكثر من كاهن وأكثر من مشرف لكل سكن. كما يمكن للكاهن أو المشرف الواحد إدارة أكثر من سكن في وقت واحد.
- **عزل البيانات**: يضمن النظام أن كل مسؤول يرى فقط بيانات السكنات التابعة له، مع إمكانية التنقل السلس بينها.
- **توزيع الأدوار الهرمي**:
    - **الأسقف**: يراقب كافة السكنات التابعة له ويقوم بالتعيينات.
    - **الكاهن والمشرف**: لديهم صلاحيات إدارية كاملة (إضافة طلاب، موظفين، منظمين) داخل السكنات المسؤولة عنهم.

### 5. التصميم البصري (Neon Theme UI/UX)
- تم اعتماد **"ثيم النيون" (Neon Theme)** العصري الذي يوازن بين الاحترافية والبساطة.
- يدعم التطبيق **الوضع الليلي (Dark Mode)** و **الوضع الفاتح (Light Mode)** مع مراعاة أعلى معايير التباين وسهولة القراءة.
- استخدام الرسوم المتحركة (Animations) عبر مكتبة `motion` لزيادة سلاسة التجربة.

## التقنيات المستخدمة
- **Frontend**: React.js with TypeScript & Vite.
- **Styling**: Tailwind CSS (Neon Design System).
- **Animations**: Framer Motion / Motion for React.
- **Icons**: Lucide React.
- **QR Code**: HTML5-QRCode for scanning and QR-Code generation.
- **Charts**: Lucide/CSS based data visualization.
